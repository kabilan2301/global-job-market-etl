# Global Job Market ETL

ETL project for global job market data.

## Structure

- `config/` - configuration files
- `data/raw/` - raw input data
- `data/processed/` - cleaned and transformed output
- `extract/` - extraction logic
- `transform/` - transformation logic
- `load/` - loading logic
- `sql/` - SQL scripts
- `logs/` - runtime logs
- `tests/` - tests
- `dashboard/` - reporting/dashboard assets
- `docs/` - documentation
- `scripts/` - helper scripts

## Usage

Run `main.py` to execute the ETL pipeline.
